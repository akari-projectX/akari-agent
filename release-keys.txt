# Pinned Ed25519 release keys (M6 agent self-update). The agent runs only
# binaries whose signed manifest verifies under one of these keys; nothing
# the panel sends can add a key. One "<base64 public key> <label>" per line.
#
# EMPTY = self-update disabled (every UpdateOffer is rejected). To enable it,
# generate the release key OFFLINE (`akari-sign keygen`, see README "Release
# signing keys"), commit its public line here, and release a new agent: only
# agents built with the key can verify releases signed by it.
#
# Rotation: add the next key here and release (both keys pinned); sign the
# following releases with both keys (`akari-sign countersign`) until every
# node runs a build that pins the next key; then drop the old key.
